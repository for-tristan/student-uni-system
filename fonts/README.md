# Fonts

Drop the Inter font files here. Download from https://fonts.google.com/specimen/Inter.

Required files (as referenced in pubspec.yaml):

- Inter-Regular.ttf
- Inter-Medium.ttf      (weight 500)
- Inter-SemiBold.ttf    (weight 600)
- Inter-Bold.ttf        (weight 700)

Without these files, Flutter will fall back to the system sans-serif. The design tokens, colors, and spacing will still be correct — only the typeface changes.
